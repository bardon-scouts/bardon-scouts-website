# Bardon Scouts website

The website of the Bardon Scout Group, built with [Hugo](https://gohugo.io/) and edited through [Sveltia CMS](https://github.com/sveltia/sveltia-cms). It's hosted on [Netlify](https://www.netlify.com/).

| Site | URL | Branch |
|---|---|---|
| Live | https://bardonscouts.org.au/ | `master` |
| Dev | https://dev--bardon-scouts-website.netlify.app/ | `dev` |

All work happens on `dev`. Merging `dev` into `master` publishes to the live site.
